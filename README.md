# Алхимия ГТА5рп

Русскоязычный справочник для Little Alchemy 2: поиск по 719 элементам, альтернативные рецепты и последовательность крафта от воздуха, земли, огня и воды.

## Как открыть

Откройте `index.html` в современном браузере. Для загрузки React и библиотеки понадобится интернет; рецепты и переводы хранятся локально в `src/elements.json`.

## Как пользоваться

1. Введите название на русском или английском.
2. Выберите элемент из результатов.
3. Справа появятся шаги крафта. Нажмите на ингредиент, чтобы узнать его рецепт.

Если для пути нужно «Время», сайт подскажет, что этот элемент открывается после 100 найденных элементов.
